Built at Kinben and in daily operational use. Source is private — happy to walk through the architecture in a conversation.

- **Pipeline Operations Console** — RAG across inspection, operations, and GIS data. Plain-language Q&A grounded in a team's own records, one-click report generation, and built-in evaluation loops tracking answer quality and time-to-decision.
- **Crude Trade Copilot** — assay parsing, non-linear blend optimization, and yield prediction from a single prompt, with exec-ready summaries. Consistent results every run, no prompt-wrangling.

## Open source

Small, self-contained projects — each runs AI locally or entirely in the browser. Useful as working references for client-side inference and RAG.

#### [LLM-on-Web](https://github.com/van007/LLM-on-Web) · [live demo](https://van007.github.io/LLM-on-Web/)
Client-side RAG chat with WebGPU-accelerated inference. Document chunking, embeddings, and retrieval run entirely in-browser — no server, no sign-up.
`JavaScript` · `Transformers.js` · `WebGPU`

#### [Prompt2PowerPoint](https://github.com/van007/Prompt2Powerpoint) · [live demo](https://van007.github.io/Prompt2Powerpoint/)
Turns a plain-language prompt into a finished PPTX deck. Pluggable backend — local LLM server or cloud API routing.
`JavaScript` · `LLM APIs`

#### [QuickTag-Images](https://github.com/van007/QuickTag-Images) · [live demo](https://van007.github.io/QuickTag-Images/)
Local AI image labeling and metadata — names and tags large image folders on-device, nothing uploaded.
`JavaScript` · `local inference`

#### [Solar-AI](https://github.com/van007/Solar-AI) · [live demo](https://van007.github.io/Solar-AI/)
Web-based solar-plant simulation and monitoring, with generation modeling and predictive-maintenance signals.
`JavaScript` · `time-series`
